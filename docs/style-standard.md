Tradition Local style standard

One set of values so every page matches. The values live as named variables at the top of src/styles/global.css. Change them there, not page by page.

Controls
Fields and dropdowns are 48 pixels tall (control-h) with pill corners, a 1.5 pixel slate border, 16 pixel regular text, a 24 pixel line height, and 18 pixels of side padding.
Every dropdown uses the same custom chevron and switches off the browser's own look, so Safari and Chrome match.
Chips, small buttons, and filter pills are 40 pixels tall (control-h-sm), 14 pixels.

Type
Eyebrow 12 bold with wide letter spacing. Headline Fraunces 60 semibold. Intro 19 regular.
Labels 13 bold, set 6 pixels above the field.
Small text is 14 pixels with a 22 pixel line height: counts, descriptions, the quiz line, checkbox labels.
Buttons are 14 bold.

Alignment rule
Every control in a row shares one height, one center line, and one label line. Never mix a native browser control with a styled one in the same row.

Spacing
Label to field 6. Field to field 14. Filter card padding 20 by 24. Card gap 24. Intro to filter card 32. Filter card to first result 32.
